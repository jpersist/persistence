JPersist is a suite of modern, high-performance, and Gradle Configuration Cache-compliant plugins that automate the configuration of enterprise Jakarta Persistence API (JPA) environments.
It provides zero-configuration support for Hibernate, EclipseLink, and OpenJPA multi-module builds.
