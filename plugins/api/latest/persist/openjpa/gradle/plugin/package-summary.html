Package persist.openjpa.gradle.plugin

Package persist.openjpa.gradle.plugin Description

Gradle plugin implementations for OpenJPA persistence integration.

This package provides three plugins that automate OpenJPA build-time tasks:

  • persist.openjpa.gradle.plugin.OpenJPAMetaModelGenerationPlugin (io.github.jpersist.openjpa-metamodelgen) — Generates JPA static canonical metamodel classes using the OpenJPA annotation processor.
  • OpenJPAEnhancementPlugin (io.github.jpersist.openjpa-enhancement) — Performs compile-time bytecode enhancement via the OpenJPA PCEnhancer tool, injecting persistence capability hooks directly into entity class binaries.
  • persist.openjpa.gradle.plugin.OpenJPAPersistencePlugin (io.github.jpersist.openjpa-persistence) — Aggregate plugin that applies both the metamodel generation and enhancement plugins in a single declaration.

All plugins support per-source-set configuration through the openjpa extension block and integrate seamlessly with the standard Gradle build lifecycle.
