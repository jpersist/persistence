Package: persist.openjpa.gradle.extension

[Groovy] Class OpenJPAExtension

    • persist.openjpa.gradle.extension.OpenJPAExtension 
    • class OpenJPAExtension
extends Object

      Source-set-scoped configuration container for OpenJPA tools.

      This class is managed inside a NamedDomainObjectContainer, which automatically instantiates and seeds a distinct configuration sandbox context for every active project source set (such as main, test, or custom variants like integrationTest). It aggregates both the metamodel generation and bytecode enhancement configuration sub-blocks.

      Since:
      1.8.0

      • Constructor Detail

        • @Inject
          OpenJPAExtension(String name, ObjectFactory objects)

          Constructs a new OpenJPAExtension instance.

          Configures the named sub-scope context and instantiates structural inner configuration extensions using the injected ObjectFactory service wrapper. Default convention values are applied for metamodel generation (enabled) and enhancement options (addDefaultConstructor = true, enforcePropertyRestrictions = false).

          Parameters:
          name - The name of the source set block.
          objects - The injected object factory for creating nested extension abstractions.

      • Method Detail

        • void enhancement(Action<? super EnhancementExtension> action)

          Configures the OpenJPA bytecode enhancement options for this source set scope via a DSL configuration closure.

          For example, inside a build script: 

           openjpa {
     main {
         enhancement {
             addDefaultConstructor = true
             enforcePropertyRestrictions = false
         }
     }
 }

          Parameters:
          action - The configuration action mapping execution targets to EnhancementExtension.

        • void metamodel(Action<? super MetaModelExtension> action)

          Configures the OpenJPA metamodel generation options for this source set scope via a DSL configuration closure.

          For example, inside a build script: 

           openjpa {
     main {
         metamodel {
             enabled = true
             logLevel = 'TRACE'
         }
     }
 }

          Parameters:
          action - The configuration action mapping execution targets to MetaModelExtension.
