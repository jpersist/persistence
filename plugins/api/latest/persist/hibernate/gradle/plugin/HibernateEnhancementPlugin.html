Package: persist.hibernate.gradle.plugin

[Groovy] Class HibernateEnhancementPlugin

    • persist.hibernate.gradle.plugin.HibernateEnhancementPlugin
    • All Implemented Interfaces and Traits:
      Plugin<Project>
      class HibernateEnhancementPlugin
extends Object
implements Plugin<Project>

      Main entry point for the Hibernate Bytecode Enhancement Plugin.

      This plugin applies the JavaPlugin, registers a customizable hibernate configuration extension block, and dynamically instantiates an independent HibernateEnhancementTask for every active project source set layout whose java.srcDirs contain at least one directory that physically exists on disk.

      To ensure absolute compliance with the Gradle Configuration Cache and incremental verification states, this plugin manages separate input/output staging directory targets, safeguarding compilation UP-TO-DATE checking parameters across multi-module build paths.

      Since 1.7.0: The enhancement task is only registered for source sets that have at least one physical Java source directory present on disk. Source sets with no existing java.srcDirs directories are silently skipped, preventing clean IDE workspaces from being cluttered with empty tasks (e.g. hibernateEnhanceTestClasses).

      Since 1.8.0: The enhancement task now delegates bytecode transformation to an isolated EnhancementWorker submitted via classLoaderIsolation. The plugin resolves the active JPA specification version from the PersistenceExtension registered by the JakartaPersistencePlugin and dynamically selects the correct Persistence Tools provider library (persistence-tools-jakarta or persistence-tools-legacy) into a per-source-set isolated classpath configuration. This decouples the enhancement task from direct Hibernate API imports and ensures the Gradle daemon's classpath remains unpolluted.
