Package: persist.jakarta.gradle.task

[Groovy] Class ProcessPersistenceDescriptor

        • persist.jakarta.gradle.task.ProcessPersistenceDescriptor 
        • @DisableCachingByDefault(because: Process overwrite persistence.xml in place)
abstract class ProcessPersistenceDescriptor
extends DefaultTask

          Gradle task that generates or merges a JPA persistence.xml descriptor.

          When a user-provided src/main/resources/META-INF/persistence.xml exists, the task operates in merge mode: it parses the existing file, applies extension-defined overrides (provider, data source, properties), injects resolved <jar-file> entries, and writes the result to the destination.

          When no source descriptor is present, the task operates in generate mode: it builds a complete persistence.xml from scratch using the PersistenceExtension DSL configuration.

          Since:
          1.1.0
