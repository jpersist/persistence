Package: persist.jakarta.gradle.extension

[Groovy] Class TenantValidationExtension

    • persist.jakarta.gradle.extension.TenantValidationExtension 
    • abstract class TenantValidationExtension
extends java.lang.Object

      Named DSL extension representing a single database tenant profile for multi-tenant schema validation.

      Each instance is identified by a unique name and carries its own JDBC connection properties. Instances are created inside the ValidationExtension.tenants named container.

      All JDBC properties default to an in-memory H2 database whose name is derived from the tenant name.

      Since:
      1.7.0
      See Also:
      ValidationExtension.tenants
