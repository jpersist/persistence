Package: persist.jakarta.gradle.extension

[Groovy] Class ValidationExtension

    • persist.jakarta.gradle.extension.ValidationExtension 
    • abstract class ValidationExtension
extends java.lang.Object

      DSL extension class for configuring database connection properties used during JPA schema validation.

      An instance of this class is embedded inside each PersistenceExtension and can be configured via the validation closure in the build script. All properties are optional; when omitted, the ValidatePersistenceSchema task falls back to an in-memory H2 database with sensible defaults.

      Since version 1.7.0, the extension supports multi-tenant validation via a named tenants container. Each tenant profile declares its own JDBC connection properties. When no tenants are configured, the base properties are used as a single default profile for backward compatibility.

      Example — single database (backward compatible):

       persistence {
     main {
         validation {
             url = 'jdbc:h2:mem:my_validation_db;DB_CLOSE_DELAY=-1'
             driver = 'org.h2.Driver'
             user = 'sa'
             password = ''
         }
     }
 }

      Example — multi-tenant validation:

       persistence {
     main {
         validation {
             tenants {
                 primary {
                     url = 'jdbc:h2:mem:primary_db;DB_CLOSE_DELAY=-1'
                 }
                 secondary {
                     url = 'jdbc:h2:mem:secondary_db;DB_CLOSE_DELAY=-1'
                 }
             }
         }
     }
 }

        • @org.gradle.api.tasks.Nested
          final org.gradle.api.NamedDomainObjectContainer<TenantValidationExtension> tenants

          The named container of multi-tenant database connection profiles.

          Each entry defines a separate tenant whose schema will be validated independently during the ValidatePersistenceSchema task. When this container is empty, the base url, driver, user, and password properties are wrapped into a single default profile automatically.
