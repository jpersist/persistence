[Groovy] Class ValidatePersistenceSchema

        • persist.jakarta.gradle.task.ValidatePersistenceSchema 
        • @DisableCachingByDefault(because: Validates active database schema state at execution time)
abstract class ValidatePersistenceSchema
extends DefaultTask

          Boots an isolated JVM worker process to validate that the JPA entity configurations perfectly match the generated schema layout using an in-memory database baseline.

            • @TaskAction
              void validate(InputChanges inputChanges)

              Executes schema validation by submitting a SchemaValidationWorker to an isolated classloader worker process.

              When executed incrementally, only entities whose source files have been added or modified are forwarded to the worker. If no tracked entity source files have changed, the task skips database bootstrapping entirely. A non-incremental (full) pass validates every discovered entity class.

              The worker receives the persistence unit names, the serialized multi-tenant connection profiles, the discovered entity class names, and the full runtime classpath. For each tenant profile, every active persistence unit is validated via the SPI-loaded persist.lint.api.spi.SchemaValidator.

              Parameters:
              inputChanges - The Gradle incremental input changes descriptor.
