Package: persist.openjpa.gradle.plugin

[Groovy] Class OpenJPAEnhancementPlugin

      • persist.openjpa.gradle.plugin.OpenJPAEnhancementPlugin 
      • class OpenJPAEnhancementPlugin
extends OpenJPABasePlugin

        Gradle plugin that performs compile-time bytecode enhancement for OpenJPA entity classes.

        This plugin registers per-source-set OpenJPAEnhanceTask instances that fork isolated JVM processes running the OpenJPA PCEnhancer tool. Enhanced entity classes gain persistence capability hooks injected directly into the compiled binaries, enabling transparent state management and dirty tracking without runtime proxies or a -javaagent.

        The plugin automatically creates an enhancement dependency configuration, sets up isolated classpath resolution per source set, and hooks the enhancement task into the standard Gradle build lifecycle between compilation and JAR packaging.

          • @Override
            void apply(Project project)

            Applies the OpenJPA bytecode enhancement configuration to the target project.

            Registers the openjpa extension container (if not already present), creates per-source-set isolated classpath configurations, registers OpenJPAEnhanceTask instances that fork the OpenJPA PCEnhancer tool, hooks them into the build lifecycle, and provisions the default org.apache.openjpa:openjpa dependency when no user override is present.

            Parameters:
            project - The target Gradle project.
