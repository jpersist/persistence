Package: persist.openjpa.gradle.extension

[Groovy] Interface MetaModelExtension

  • interface MetaModelExtension

    Configuration options for the OpenJPA static canonical metamodel generation processor.

    This interface exposes lazy Property attributes that control how the OpenJPA annotation processor generates JPA static metamodel classes (e.g., Entity_) from annotated entity sources during the compilation phase.

    Example configuration block inside a build script: 

     openjpa {
     main {
         metamodel {
             enabled = true
             logLevel = 'TRACE'
             source = 8
         }
     }
 }
