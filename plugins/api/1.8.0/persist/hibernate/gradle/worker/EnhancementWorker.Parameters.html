Package: persist.hibernate.gradle.worker

[Groovy] Interface EnhancementWorker.Parameters

  • static interface EnhancementWorker.Parameters
extends WorkParameters

    Parameter interface for the EnhancementWorker work action.

    Carries the JPA version, input/output directories, the project's compilation classpath, and the four bytecode enhancement toggle flags from the HibernateEnhancementTask into the isolated worker process.

    1.8.0
