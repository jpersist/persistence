jPersist — Jakarta Persistence Gradle Plugins

jPersist is a suite of Gradle plugins that simplify development with Jakarta Persistence API (JPA) frameworks. It automates key build-time tasks — descriptor generation & merging, schema validation, static metamodel generation, bytecode enhancement/weaving, GraalVM native image metadata generation, and static compile-time named query linting — for EclipseLink, Hibernate, and OpenJPA.

Available Plugins

Jakarta Persistence

Plugin IDDescription
io.github.jpersist.jpa Manages Jakarta Persistence (JPA) descriptor generation and merging, schema validation, GraalVM native image metadata generation, and static compile-time named query linting. Creates the jpa dependency configuration for platform/BOM version alignment and registers the persistence extension DSL with processPersistenceDescriptor, validatePersistenceSchema, generateJPAGraalVMMetadata, and lintNamedQueries tasks. See JakartaPersistencePlugin.

EclipseLink

Plugin IDDescription

io.github.jpersist.eclipse-static-weave Performs compile-time bytecode weaving via the EclipseLink StaticWeave tool. See EclipseStaticWeavePlugin.
io.github.jpersist.eclipse-persistence Aggregate plugin applying both EclipseLink modelgen and static weave plugins. See EclipsePersistencePlugin.

Hibernate

io.github.jpersist.hibernate-jpamodelgen Registers the Hibernate JPA annotation processor for static metamodel generation. See HibernateJpamodelgenPlugin.

io.github.jpersist.hibernate-persistence Aggregate plugin applying both Hibernate modelgen and enhancement plugins. See HibernatePersistencePlugin.

OpenJPA

What's New in v1.8.0

Version 1.8.0 introduces Apache OpenJPA provider support and consolidated build reporting:

  • OpenJPA Provider Support — A new openjpa-persistence aggregate plugin brings first-class Apache OpenJPA support to jPersist. It applies the core JPA plugin together with two new OpenJPA-specific plugins: openjpa-metamodelgen for static canonical metamodel generation, and openjpa-enhancement for compile-time PCEnhancer bytecode enhancement executed in an isolated JVM process.
  • OpenJPA DSL Extension — The new OpenJPAExtension provides per-source-set configuration for OpenJPA, with nested metaModel and enhancement blocks. An enhancement dependency configuration is created for declaring PCEnhancer classpath dependencies.
  • Consolidated Reporting Architecture — All build-time report outputs (persistence descriptors, GraalVM metadata, lint reports) are now unified under ${buildDir}/reports/persistence/. The reflectConfigFile property replaces the deprecated outputFile on the GraalVM metadata generation task.
  • GraalVM Metadata Property Rename — The generateJPAGraalVMMetadata task introduces reflectConfigFile as the primary output property. The former outputFile property is deprecated since v1.8.0.

Quick Start

plugins {
    id 'io.github.jpersist.hibernate-persistence'  // or 'eclipse-persistence' / 'openjpa-persistence'
}

dependencies {
    jpa platform('org.hibernate.orm:hibernate-platform:6.6.5.Final')
}

Key Design Principles

  • No hardcoded dependency versions — The plugins add JPA engine dependencies without version strings. Use the jpa configuration with a platform BOM to centrally manage versions.
  • Configuration Cache compliant — All plugins and tasks are fully compatible with Gradle's Configuration Cache for maximum build performance.
  • Incremental build support — Tasks use proper input/output tracking and produce UP-TO-DATE or NO-SOURCE outcomes when appropriate.
  • Per-source-set configuration — Plugins automatically configure tasks for every source set (main, test, custom variants).
  • Eclipse IDE integration — Plugins hook into Eclipse Buildship to register generated source directories in the IDE classpath.
  • Consolidated reporting — All build-time reports (descriptors, GraalVM metadata, lint reports) are output under a unified reports/persistence/ directory tree.
  • Provider-agnostic core — The io.github.jpersist.jpa core plugin is shared across EclipseLink, Hibernate, and OpenJPA aggregator plugins, ensuring consistent descriptor generation and validation behavior regardless of the chosen JPA provider.

Package Organization

  • persist.jakarta.gradle.plugin — Jakarta Persistence plugin for JPA descriptor generation and version management.
  • persist.jakarta.gradle.extension — Jakarta Persistence DSL extension configuration model, including XML formatting options.
  • persist.jakarta.gradle.task — Jakarta Persistence build-time task implementations, including schema validation, GraalVM metadata generation, and named query linting.
  • persist.jakarta.gradle.worker — Gradle Worker API implementations for isolated JPA schema validation and named query analysis.
  • persist.jakarta.gradle.task.delegate — Version-specific strategy delegates for JPA persistence descriptor processing.
  • persist.jakarta.gradle.task.registry — Registry for mapping JPA specification versions to descriptor processing strategies.
  • persist.eclipse.gradle.plugin — EclipseLink plugin implementations.
  • persist.eclipse.gradle.extension — EclipseLink DSL extension configuration model.
  • persist.eclipse.gradle.task — EclipseLink build-time task implementations.
  • persist.hibernate.gradle.plugin — Hibernate plugin implementations.
  • persist.hibernate.gradle.extension — Hibernate DSL extension configuration model.
  • persist.hibernate.gradle.task — Hibernate build-time task implementations.
  • persist.openjpa.gradle.plugin — OpenJPA plugin implementations, including the aggregate persistence, metamodel generation, and bytecode enhancement plugins.
  • persist.openjpa.gradle.extension — OpenJPA DSL extension configuration model with MetaModel and Enhancement nested blocks.
  • persist.openjpa.gradle.task — OpenJPA build-time task implementations, including PCEnhancer bytecode enhancement.
