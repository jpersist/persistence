Package persist.eclipse.gradle.plugin

Package persist.eclipse.gradle.plugin Description

Gradle plugin implementations for EclipseLink JPA integration.

This package provides three plugins that automate EclipseLink build-time tasks:

  • persist.eclipse.gradle.plugin.EclipseJpaModelgenPlugin (io.github.jpersist.eclipse-jpa-modelgen) — Generates JPA static canonical metamodel classes using the EclipseLink annotation processor.
  • persist.eclipse.gradle.plugin.EclipseStaticWeavePlugin (io.github.jpersist.eclipse-static-weave) — Performs compile-time bytecode weaving via the EclipseLink StaticWeave tool, enabling lazy loading and dirty tracking without a runtime -javaagent.
  • persist.eclipse.gradle.plugin.EclipsePersistencePlugin (io.github.jpersist.eclipse-persistence) — Aggregate plugin that applies both the modelgen and static weave plugins in a single declaration.

All plugins are fully compliant with Gradle's Configuration Cache and support incremental builds with proper UP-TO-DATE and NO-SOURCE tracking.
