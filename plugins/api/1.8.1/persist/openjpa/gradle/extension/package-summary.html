Package persist.openjpa.gradle.extension

Package persist.openjpa.gradle.extension Description

DSL extension classes for configuring OpenJPA Gradle plugin behavior.

This package contains the configuration model exposed to build scripts via the openjpa extension block. It provides per-source-set configuration through a NamedDomainObjectContainer, allowing independent settings for main, test, and custom source set variants.

Key classes:

  • persist.openjpa.gradle.extension.OpenJPAExtension — Source-set-scoped configuration container for OpenJPA tools.
  • persist.openjpa.gradle.extension.MetaModelExtension — Configuration attributes for the OpenJPA canonical metamodel generator, including logging level, source version, and naming conventions.
  • persist.openjpa.gradle.extension.EnhancementExtension — Configuration attributes for the OpenJPA bytecode enhancement engine, controlling default constructor generation and property restriction enforcement.
