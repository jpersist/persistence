Package persist.hibernate.gradle.worker

Package persist.hibernate.gradle.worker Description

Gradle Worker API implementations for Hibernate compile-time bytecode enhancement.

This package contains the worker action and its parameter interface used to perform classloader-isolated bytecode enhancement of Hibernate entity classes inside a worker process managed by Gradle's WorkerExecutor.

  • persist.hibernate.gradle.worker.EnhancementWorker — WorkAction that loads the Persistence Tools SPI factories and the Hibernate bytecode engine, iterates over every compiled .class file, applies the two-pass enhancement cycle (type discovery followed by byte transformation), and writes the results to an isolated target directory.
  • persist.hibernate.gradle.worker.EnhancementWorker.Parameters — Parameter interface carrying the JPA version, input/output directories, the project's compilation classpath, and the four bytecode enhancement toggle flags from the HibernateEnhancementTask into the isolated worker process.
