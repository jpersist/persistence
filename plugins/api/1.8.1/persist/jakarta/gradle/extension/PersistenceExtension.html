Package: persist.jakarta.gradle.extension

[Groovy] Class PersistenceExtension

    • persist.jakarta.gradle.extension.PersistenceExtension 
    • abstract class PersistenceExtension
extends Object

      Named DSL extension for the Jakarta Persistence plugin, scoped per Java source set.

      Instances of this class are managed inside a NamedDomainObjectContainer registered under the persistence project extension. The plugin automatically creates one instance per Java source set (e.g. main, test), using the source set name as the container key. Each instance exposes the JPA specification version and a nested NamedDomainObjectContainer of PersistenceUnitExtension instances, allowing build scripts to declaratively define one or more persistence units per source set.

      Declared as abstract so that Gradle's managed-property engine can generate the backing implementation for lazy Property fields.

      Example usage:

       persistence {
     main {
         persistenceUnits {
             'my-unit' {
                 provider = 'org.hibernate.jpa.HibernatePersistenceProvider'
             }
         }
     }
 }
      Since:
      1.1.0

        • @Nested
          final LinterExtension linter

          Nested configuration for the static compile-time @NamedQuery analysis linter.

          Configurable via the linter(org.gradle.api.Action) DSL method. By default the linter is enabled, fails the build on errors, and reports warnings.

          Since:
          1.6.0
          See Also:
          LinterExtension

        • final NamedDomainObjectContainer<PersistenceUnitExtension> persistenceUnits

          Container of named PersistenceUnitExtension instances.

          Each entry maps to a <persistence-unit> element in the generated or merged persistence.xml. The container name becomes the name attribute of the unit.

        • final ValidationExtension validation

          Nested configuration for JPA schema validation database connection properties.

          Configurable via the validation(Action) DSL method. When no properties are set, the ValidatePersistenceSchema task defaults to an in-memory H2 database.

          Since:
          1.5.0
          See Also:
          ValidationExtension

        • @Input
          abstract MapProperty<String, String> getOutputProperties()

          Key-value pairs passed to the XML Transformer that formats the generated persistence.xml.

          Defaults include indent=yes, omit-xml-declaration=no, encoding=UTF-8, and an indent amount of 4 spaces. Entries can be overridden via the transformer(Closure) DSL block or the outputProperty(String, String) method.
