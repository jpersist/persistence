Package persist.jakarta.gradle.util

Package persist.jakarta.gradle.util Description

Internal utilities for Gradle worker execution isolation and persistence SPI resolution.

This package provides helper facilities for configuring isolated worker executions and discovering persistence provider SPI implementations across classloader and JPMS modular runtime environments.

  • JPMSWorkerSupport — Configures Gradle WorkerExecutor work queues using either modular JPMS process isolation (when module-info.class is detected) or standard classloader isolation, dynamically configuring JVM module arguments, module paths, and reflective --add-opens flags.
  • PersistenceServiceResolver — Resolves versioned persistence.tools.spi.PersistenceServiceProvider instances via ServiceLoader, checking both modular JPMS boot layers and the current thread's context classloader.
