= Getting Started

This section covers the requirements and basic setup to start using JPersist plugins in your Gradle project.

== Requirements

* **Gradle:** 7.4+ or 8.x+ / 9.x+
* **Java:** JDK 17 or higher (required by modern Jakarta specifications)

== Choosing a Plugin

JPersist provides three main plugins depending on your JPA provider:

[cols="1,2,1"]
|===
| Plugin ID | Description | Provider

| `io.github.jpersist.jpa`
| Generates or merges `persistence.xml` descriptors, validates persistence schema against the database schema, and generates JPA GraalVM native image metadata (`reflect-config.json`)
| Provider-agnostic

| `io.github.jpersist.hibernate-persistence`
| Descriptor generation, metamodel generation, and bytecode enhancement
| Hibernate

| `io.github.jpersist.eclipse-persistence`
| Descriptor generation, metamodel generation, and static weaving
| EclipseLink
|===

TIP: The provider-specific plugins (`hibernate-persistence` and `eclipse-persistence`) automatically apply the `io.github.jpersist.jpa` plugin, so you only need to apply one.

== Applying the Plugin

=== Hibernate example

[source,groovy,indent=0,role="primary",subs="attributes+"]
.Groovy
----
plugins {
    id 'io.github.jpersist.hibernate-persistence' version '{project-version}'
}
----

[source,kotlin,indent=0,role="secondary",subs="attributes+"]
.Kotlin
----
plugins {
    id("io.github.jpersist.hibernate-persistence") version "{project-version}"
}
----

=== EclipseLink example

[source,groovy,indent=0,role="primary",subs="attributes+"]

plugins {

----

plugins {

== Adding Dependencies

Use the `jpa` configuration to declare your JPA provider platform BOM. This centralizes version management across all compilation scopes.

=== Hibernate example

[source,groovy,indent=0,role="primary"]
.Groovy
----
dependencies {
    jpa platform('org.hibernate.orm:hibernate-platform:6.6.56.Final')

    implementation 'org.hibernate.orm:hibernate-core'
}
----

[source,kotlin,indent=0,role="secondary"]
.Kotlin
----
dependencies {
    jpa(platform("org.hibernate.orm:hibernate-platform:6.6.56.Final"))

    implementation("org.hibernate.orm:hibernate-core")
}
----

=== EclipseLink example

[source,groovy,indent=0,role="primary"]
.Groovy
----
dependencies {
    jpa platform('org.eclipse.persistence:org.eclipse.persistence.parent:4.0.9')

    compileOnly 'jakarta.persistence:jakarta.persistence-api'
    implementation 'org.eclipse.persistence:org.eclipse.persistence.core'
}
----

[source,kotlin,indent=0,role="secondary"]
.Kotlin
----
dependencies {
    jpa(platform("org.eclipse.persistence:org.eclipse.persistence.parent:4.0.9"))

    compileOnly("jakarta.persistence:jakarta.persistence-api")
    implementation("org.eclipse.persistence:org.eclipse.persistence.core")
}
----

That's it — no additional XML configuration or annotation processing setup is required.
The plugin automatically detects your entity classes and generates the appropriate `persistence.xml` at build time.
