Package: persist.jakarta.gradle.extension

[Groovy] Class PersistenceUnitExtension

    • persist.jakarta.gradle.extension.PersistenceUnitExtension 
    • abstract class PersistenceUnitExtension
extends java.lang.Object

      Per-unit DSL configuration for a single <persistence-unit> element.

      Instances are created automatically by the org.gradle.api.NamedDomainObjectContainer in PersistenceExtension.persistenceUnits. The container entry name becomes the name attribute of the persistence unit.

      Declared as abstract so that Gradle's managed-property engine can generate the backing implementation for lazy org.gradle.api.provider.Property fields.

      Since:
      1.1.0

          Declaratively configures a local project dependency layout mapping inside the descriptor.

          Automatically hooks into the target module's standard Java Jar task lifecycle properties lazily to avoid configuration-phase task ordering issues.

          Example usage:
