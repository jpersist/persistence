[Groovy] Class AbstractDescriptorProcessorDelegate

    • persist.jakarta.gradle.task.delegate.AbstractDescriptorProcessorDelegate
    • All Implemented Interfaces and Traits:
      DescriptorProcessorDelegate
      abstract class AbstractDescriptorProcessorDelegate
extends java.lang.Object
implements DescriptorProcessorDelegate

      Base implementation of DescriptorProcessorDelegate that provides the common merge and generate logic for all JPA specification versions.

      Concrete subclasses only need to declare which specification versions they support via DescriptorProcessorDelegate.getSupportedVersions. All XML node manipulation is isolated inside the static Helper inner class to prevent Groovy's dynamic method dispatch from routing calls through Gradle's decorated task proxy.
