Package persist.jakarta.gradle.task

Package persist.jakarta.gradle.task Description

Custom Gradle task implementations for Jakarta Persistence descriptor processing.

This package contains the task classes that perform the actual persistence.xml generation and merging work orchestrated by the Jakarta Persistence plugin.

  • persist.jakarta.gradle.task.ProcessPersistenceDescriptor — Generates a new persistence.xml from the plugin extension DSL or merges an existing user-provided descriptor with extension-defined overrides and resolved jar-file entries. Disabled persistence units are automatically excluded, and the final output is formatted according to configurable transformer properties. Processing is delegated to version-specific strategy implementations resolved via persist.jakarta.gradle.task.registry.JPAVersionStrategyRegistry.
  • ValidatePersistenceSchema — Boots an isolated JVM worker process to validate that JPA entity configurations match the database schema. Uses classloader isolation via Gradle's org.gradle.workers.WorkerExecutor and delegates the actual validation to persist.jakarta.gradle.worker.SchemaValidationWorker.
  • GenerateJPAGraalVMMetadata — Generates a GraalVM native image reflect-config.json file containing all discovered JPA entity metadata classes to support ahead-of-time (AOT) reflection registration.
