      Main entry point for the EclipseLink Static Weaving Plugin.

      This plugin applies the org.gradle.api.plugins.JavaPlugin and registers a high-performance, incremental bytecode modification task for every discovered source set container in the project. It programmatically triggers EclipseLink's StaticWeave execution framework post-compilation, transforming standard JPA entities in-place within the compilation pipeline output boundaries. When the jpa configuration is present (e.g. via JakartaPersistencePlugin), the weave configuration lazily extends from it to inherit platform version constraints.

      This enables performance optimizations such as strict lazy loading, fetch graph mechanics, and advanced inline dirty tracking without requiring an active -javaagent JVM argument at runtime.
