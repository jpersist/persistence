[Groovy] Class HibernateEnhancementTask

        • persist.hibernate.gradle.task.HibernateEnhancementTask 
        • @org.gradle.work.DisableCachingByDefault(because: Enhancement modifies classes in place)
abstract class HibernateEnhancementTask
extends org.gradle.api.DefaultTask

          A custom Gradle task that programmatically performs compile-time bytecode enhancement on Hibernate entities.

          This task parses a directory of raw compiled classes and runs Hibernate's internal org.hibernate.bytecode.enhance.spi.Enhancer engine. It rewrites entity class definitions to support optimizations such as lazy initialization at the field level, inline change tracking (dirty checking), and automatic bidirectional association management. By writing enhanced results out to an isolated target directory, the task preserves full compatibility with Gradle's Configuration Cache and incremental build system.

            • @org.gradle.api.tasks.TaskAction
              void enhance()

              The main execution block for the task.

              Constructs a specialized, isolated java.net.URLClassLoader linking the raw class sources and the complete compile classpath. It establishes a custom org.hibernate.bytecode.enhance.spi.DefaultEnhancementContext mapping your configuration flags, invokes the multi-pass Hibernate toolbelt (performing both type discovery and byte transformation), and populates the separate target directory with copy/rewrite results.
