Package: persist.eclipse.gradle.extension

[Groovy] Class JpaModelgenExtension

    • persist.eclipse.gradle.extension.JpaModelgenExtension 
    • abstract class JpaModelgenExtension
extends java.lang.Object

      Holds specific configuration attributes for the EclipseLink Canonical Model Generator.

      This class exposes lazy properties to manage the location of the persistence.xml file. It is declared as an abstract class to allow Gradle's runtime orchestration engine to intercept property tracking and decoration APIs natively.

      Since:
      1.0.0
