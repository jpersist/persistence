Package persist.hibernate.gradle.extension

Package persist.hibernate.gradle.extension Description

DSL extension classes for configuring Hibernate Gradle plugin behavior.

This package contains the configuration model exposed to build scripts via the hibernate extension block, providing fine-grained control over compile-time bytecode enhancement parameters.

  • HibernateExtension — Root extension serving as the hibernate { ... } DSL namespace, hosting nested configuration sub-blocks.
  • persist.hibernate.gradle.extension.EnhancementExtension — Configuration interface exposing toggles for lazy initialization, dirty tracking, association management, and extended enhancement.
since:
1.0.0
