      Gradle plugin that manages Jakarta Persistence (JPA) descriptor generation.

      Registered with plugin id io.github.jpersist.jpa, this plugin:

      1. Applies the org.gradle.api.plugins.JavaPlugin.
      2. Creates a jpa dependency configuration for propagating platform/BOM version constraints into standard Java configurations (implementation, compileOnly, annotationProcessor, runtimeOnly). When the org.gradle.api.plugins.JavaLibraryPlugin is applied, the api and compileOnlyApi configurations are also extended from jpa.
      3. Registers the persistence org.gradle.api.NamedDomainObjectContainer of PersistenceExtension as the top-level DSL extension.
      4. For each Java source set (e.g. main, test):
        • Creates a jarFile (or <sourceSet>JarFile) dependency configuration for declaring module JARs to be injected as <jar-file> entries. The jarFile configuration extends implementation (and api when the java-library plugin is present).
        • Automatically initializes a PersistenceExtension instance in the container, keyed by the source set name.
        • Automatically parses any existing persistence.xml template in the source set's resources and pre-registers the <persistence-unit> names into the extension, so they can be configured from the build script without explicit re-declaration.
        • Registers a processPersistenceDescriptor (or process<SourceSet>PersistenceDescriptor) ProcessPersistenceDescriptor task that generates or merges the final persistence.xml.
        • Registers the generated resources directory into the source set so that IDEs such as Eclipse Buildship and IntelliJ can index the directory and resolve META-INF/persistence.xml instantly.
        • Wires the task output into the source set's processResources so the generated descriptor ends up in the JAR.
        • Registers a validatePersistenceSchema (or validate<SourceSet>PersistenceSchema) ValidatePersistenceSchema task that validates entity mappings against the database schema using an isolated worker process.
        • Registers a generateJPAGraalVMMetadata (or generate<SourceSet>JPAGraalVMMetadata) GenerateJPAGraalVMMetadata task that produces a GraalVM reflect-config.json for all discovered JPA entity classes.

      Individual persistence units can be skipped by setting their enabled property to false. The generated XML output can be customized via the outputProperties map or the transformer DSL block.

      Persistence units already declared in a user-provided persistence.xml template are automatically registered into the extension at configuration time, allowing build scripts to customise them (e.g. disable or override properties) without re-declaring them.

      This plugin replaces the deprecated persistence-gradle-plugin (io.github.jpersist.persistence).
