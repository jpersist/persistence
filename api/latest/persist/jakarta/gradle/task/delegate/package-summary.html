Package persist.jakarta.gradle.task.delegate

Package persist.jakarta.gradle.task.delegate Description

Version-specific strategy delegates for JPA persistence descriptor processing.

This package contains the DescriptorProcessorDelegate strategy interface and its implementations, each handling descriptor generation and merging for a specific set of JPA specification versions.

  • DescriptorProcessorDelegate — Strategy interface governing the descriptor generation and merge phases.
  • persist.jakarta.gradle.task.delegate.AbstractDescriptorProcessorDelegate — Base implementation providing common merge and generate logic for all JPA specification versions.
  • JPA20DescriptorProcessorDelegate — Delegate for the JPA 2.0 specification.
  • JPA21DescriptorProcessorDelegate — Delegate for the JPA 2.1 and 2.2 specifications.
  • JPA30DescriptorProcessorDelegate — Delegate for the JPA 3.0 and 3.1 specifications.
  • persist.jakarta.gradle.task.delegate.JPA32DescriptorProcessorDelegate — Delegate for the JPA 3.2 specification.
