jPersist — Jakarta Persistence Gradle Plugins

jPersist is a suite of Gradle plugins that simplify development with Jakarta Persistence API (JPA) frameworks. It automates two key build-time tasks — static metamodel generation and bytecode enhancement/weaving — for both EclipseLink and Hibernate.

Available Plugins

Jakarta Persistence

Plugin IDDescription
io.github.jpersist.jpa Manages Jakarta Persistence (JPA) descriptor generation, creates the {@code jpa} dependency configuration for platform/BOM version alignment, and registers the {@code persistence} extension DSL with {@code processPersistenceDescriptor} tasks. Supports skipping generation of individual persistence units via the {@code enabled} flag and customizing the XML output formatting through configurable transformer properties. See {@link persist.jakarta.gradle.plugin.JakartaPersistencePlugin}.

Platform (deprecated)

Plugin IDDescription
io.github.jpersist.persistence-platform Deprecated — replaced by io.github.jpersist.jpa. Declares a JPA implementation platform (BOM) dependency for centralized version alignment across all configurations. See {@link persist.platform.gradle.plugin.PersistencePlatformPlugin}.

EclipseLink

Plugin IDDescription
io.github.jpersist.eclipse-jpa-modelgen Generates JPA static canonical metamodel classes using the EclipseLink annotation processor. See {@link persist.eclipse.gradle.plugin.EclipseJpaModelgenPlugin}.
io.github.jpersist.eclipse-static-weave Performs compile-time bytecode weaving via the EclipseLink StaticWeave tool. See {@link persist.eclipse.gradle.plugin.EclipseStaticWeavePlugin}.
io.github.jpersist.eclipse-persistence Aggregate plugin applying both EclipseLink modelgen and static weave plugins. See {@link persist.eclipse.gradle.plugin.EclipsePersistencePlugin}.

Hibernate

Plugin IDDescription
io.github.jpersist.hibernate-jpamodelgen Registers the Hibernate JPA annotation processor for static metamodel generation. See {@link persist.hibernate.gradle.plugin.HibernateJpamodelgenPlugin}.
io.github.jpersist.hibernate-enhancement Performs compile-time bytecode enhancement using Hibernate's Enhancer engine. See {@link persist.hibernate.gradle.plugin.HibernateEnhancementPlugin}.
io.github.jpersist.hibernate-persistence Aggregate plugin applying both Hibernate modelgen and enhancement plugins. See {@link persist.hibernate.gradle.plugin.HibernatePersistencePlugin}.

What's New in v1.5.0

Version 1.5.0 introduces three major features to the Jakarta Persistence plugin (io.github.jpersist.jpa):

  • JPA Schema Validation — A new {@link persist.jakarta.gradle.task.ValidatePersistenceSchema validatePersistenceSchema} task boots an isolated JVM worker process to validate that JPA entity mappings match the database schema. The task uses Gradle's {@link org.gradle.workers.WorkerExecutor} with classloader isolation to avoid classpath conflicts with the Gradle daemon. Database connection properties are configurable via the new {@link persist.jakarta.gradle.extension.ValidationExtension validation} DSL block inside each source set's {@code persistence} extension: 
    persistence {
    main {
        validation {
            url = 'jdbc:h2:mem:my_validation_db;DB_CLOSE_DELAY=-1'
            driver = 'org.h2.Driver'
            user = 'sa'
            password = ''
        }
    }
}
    When no properties are configured, the task defaults to an in-memory H2 database. See {@link persist.jakarta.gradle.worker.SchemaValidationWorker} for implementation details.
  • GraalVM Native Image Support — A new {@link persist.jakarta.gradle.task.GenerateJPAGraalVMMetadata generateJPAGraalVMMetadata} task produces a {@code reflect-config.json} file containing all discovered JPA entity classes, enabling ahead-of-time (AOT) reflection registration for GraalVM native image compilation.
  • Validation DSL Extension — The new {@link persist.jakarta.gradle.extension.ValidationExtension} interface provides optional JDBC connection properties ({@code url}, {@code driver}, {@code user}, {@code password}) embedded inside {@link persist.jakarta.gradle.extension.PersistenceExtension}. It is accessible via the {@link persist.jakarta.gradle.extension.PersistenceExtension#validation(org.gradle.api.Action) validation(Action)} DSL method.

Quick Start

plugins {
    id 'io.github.jpersist.hibernate-persistence'  // or 'io.github.jpersist.eclipse-persistence'
}

dependencies {
    jpa platform('org.hibernate.orm:hibernate-platform:6.6.5.Final')
}

Key Design Principles

  • No hardcoded dependency versions — The plugins add JPA engine dependencies without version strings. Use the jpa configuration with a platform BOM to centrally manage versions.
  • Configuration Cache compliant — All plugins and tasks are fully compatible with Gradle's Configuration Cache for maximum build performance.
  • Incremental build support — Tasks use proper input/output tracking and produce UP-TO-DATE or NO-SOURCE outcomes when appropriate.
  • Per-source-set configuration — Plugins automatically configure tasks for every source set (main, test, custom variants).
  • Eclipse IDE integration — Plugins hook into Eclipse Buildship to register generated source directories in the IDE classpath.

Package Organization

  • {@link persist.jakarta.gradle.plugin} — Jakarta Persistence plugin for JPA descriptor generation and version management.
  • {@link persist.jakarta.gradle.extension} — Jakarta Persistence DSL extension configuration model, including XML formatting options.
  • {@link persist.jakarta.gradle.task} — Jakarta Persistence build-time task implementations, including schema validation and GraalVM metadata generation.
  • {@link persist.jakarta.gradle.worker} — Gradle Worker API implementations for isolated JPA schema validation.
  • {@link persist.platform.gradle.plugin} — (Deprecated) Platform alignment plugin for centralized version management.
  • {@link persist.eclipse.gradle.plugin} — EclipseLink plugin implementations.
  • {@link persist.eclipse.gradle.extension} — EclipseLink DSL extension configuration model.
  • {@link persist.eclipse.gradle.task} — EclipseLink build-time task implementations.
  • {@link persist.hibernate.gradle.plugin} — Hibernate plugin implementations.
  • {@link persist.hibernate.gradle.extension} — Hibernate DSL extension configuration model.
  • {@link persist.hibernate.gradle.task} — Hibernate build-time task implementations.
