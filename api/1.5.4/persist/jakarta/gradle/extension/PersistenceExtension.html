Package: persist.jakarta.gradle.extension

[Groovy] Class PersistenceExtension

    • persist.jakarta.gradle.extension.PersistenceExtension 
    • abstract class PersistenceExtension
extends java.lang.Object

      Named DSL extension for the Jakarta Persistence plugin, scoped per Java source set.

      Instances of this class are managed inside a org.gradle.api.NamedDomainObjectContainer registered under the persistence project extension. The plugin automatically creates one instance per Java source set (e.g. main, test), using the source set name as the container key. Each instance exposes the JPA specification version and a nested org.gradle.api.NamedDomainObjectContainer of PersistenceUnitExtension instances, allowing build scripts to declaratively define one or more persistence units per source set.

      Declared as abstract so that Gradle's managed-property engine can generate the backing implementation for lazy org.gradle.api.provider.Property fields.

      Example usage:

       persistence {
     main {
         persistenceUnits {
             'my-unit' {
                 provider = 'org.hibernate.jpa.HibernatePersistenceProvider'
             }
         }
     }
 }
      Since:
      1.1.0

        • final org.gradle.api.NamedDomainObjectContainer<PersistenceUnitExtension> persistenceUnits

          Container of named PersistenceUnitExtension instances.

          Each entry maps to a <persistence-unit> element in the generated or merged persistence.xml. The container name becomes the name attribute of the unit.

        • final ValidationExtension validation

          Nested configuration for JPA schema validation database connection properties.

          Configurable via the validation(Action) DSL method. When no properties are set, the ValidatePersistenceSchema task defaults to an in-memory H2 database.
