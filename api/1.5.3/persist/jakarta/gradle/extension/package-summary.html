Package persist.jakarta.gradle.extension

Package persist.jakarta.gradle.extension Description

DSL extension classes for configuring the Jakarta Persistence Gradle plugin.

This package contains the configuration model exposed to build scripts via the persistence extension block. It allows declarative definition of one or more JPA persistence units through a org.gradle.api.NamedDomainObjectContainer, enabling the plugin to generate or merge a persistence.xml descriptor at build time.

Key classes:

  • persist.jakarta.gradle.extension.PersistenceExtension — Top-level extension providing the JPA specification version, XML transformer output properties for formatting the generated descriptor, and a container of named persistence-unit configurations.
  • PersistenceUnitExtension — Per-unit configuration attributes such as provider, transaction type, data source, mapping files, JPA properties, and an enabled flag to skip generation of individual persistence units.
  • persist.jakarta.gradle.extension.ValidationExtension — Optional JDBC connection properties (URL, driver, user, password) used by the schema validation task. Defaults to an in-memory H2 database when not configured.
