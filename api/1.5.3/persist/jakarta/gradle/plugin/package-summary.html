Package persist.jakarta.gradle.plugin

Package persist.jakarta.gradle.plugin Description

Gradle plugin implementation for Jakarta Persistence (JPA) integration.

This package provides the core plugin that automates JPA descriptor management at build time:

  • persist.jakarta.gradle.plugin.JakartaPersistencePlugin (io.github.jpersist.jpa) — Registers the persistence extension DSL, the jpa and jarFile dependency configurations, and the processPersistenceDescriptor task that generates or merges the final persistence.xml into the build output. Supports skipping generation of individual persistence units, customizing the XML output formatting via transformer properties, smoothly extending the extra configurations of the org.gradle.api.plugins.JavaLibraryPlugin plugin when it is applied, and automatically registering persistence units found in a user-provided persistence.xml template. Additionally registers a validatePersistenceSchema task for schema validation using an isolated worker process and a generateJPAGraalVMMetadata task for generating GraalVM native image reflection configuration.

The plugin is designed as a replacement for the deprecated persistence-gradle-plugin and is fully compliant with Gradle's Configuration Cache.
