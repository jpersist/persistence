Package persist.hibernate.gradle.plugin

Package persist.hibernate.gradle.plugin Description

Gradle plugin implementations for Hibernate JPA integration.

This package provides three plugins that automate Hibernate build-time tasks:

  • persist.hibernate.gradle.plugin.HibernateJpamodelgenPlugin (io.github.jpersist.hibernate-jpamodelgen) — Registers the Hibernate JPA annotation processor to generate static canonical metamodel classes for type-safe Criteria API queries.
  • HibernateEnhancementPlugin (io.github.jpersist.hibernate-enhancement) — Performs compile-time bytecode enhancement using Hibernate's Enhancer engine, enabling lazy initialization, dirty tracking, and association management without a runtime agent.
  • persist.hibernate.gradle.plugin.HibernatePersistencePlugin (io.github.jpersist.hibernate-persistence) — Aggregate plugin that applies both the modelgen and enhancement plugins in a single declaration.

All plugins are fully compliant with Gradle's Configuration Cache and support incremental builds with proper UP-TO-DATE and NO-SOURCE tracking.
