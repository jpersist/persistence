Persistence Tools Core API & SPI

The Persistence Tools API module ({@code io.github.jpersist.tools.api}) provides vendor-agnostic abstractions and Service Provider Interfaces (SPI) for build-time validation, query parsing, schema verification, and bytecode enhancement of JPA persistence artifacts.

By decoupling application tooling and build plugins from specific JPA provider implementations, this module enables consistent build-time analysis across different persistence specifications (e.g. Jakarta Persistence JPA 3.x and legacy Java Persistence JPA 2.x).

Architecture & Key Contracts

The API is divided into two primary package layers:

1. Public API Contracts (persistence.tools)

Defines the consumer-facing interfaces and data models for persistence tooling:

  • {@link persistence.tools.Enhancer} — Transforms compiled entity class bytecode at build time to incorporate runtime optimizations such as lazy-loading proxies, inline dirty tracking, and bidirectional association management.
  • {@link persistence.tools.NamedObjectParser} — Validates named JPQL queries and stored procedure declarations against the entity metamodel, returning rich metadata descriptors.
  • {@link persistence.tools.SchemaValidator} — Validates the entity metamodel against a live database schema via JDBC connections.
  • {@link persistence.tools.NamedObjectDescriptor} — Immutable descriptor encapsulating the validation results, target type, query/procedure name, and extracted parameter definitions.
  • {@link persistence.tools.NamedObjectType} — Enumeration classifying named persistence objects ({@link persistence.tools.NamedObjectType#QUERY QUERY} or {@link persistence.tools.NamedObjectType#STORED_PROCEDURE STORED_PROCEDURE}).
  • {@link persistence.tools.PersistenceLinter} — Common marker interface for all persistence linting components.

2. Service Provider Interfaces (persistence.tools.spi)

Defines the factory interfaces and runtime discovery mechanisms implemented by provider modules:

  • {@link persistence.tools.spi.PersistenceServiceProvider} — Common root SPI for version-to-namespace mapping and {@link java.util.ServiceLoader}-based factory resolution.
  • {@link persistence.tools.spi.EnhancerProvider} — Factory SPI for discovering and instantiating namespace-specific bytecode enhancers.
  • {@link persistence.tools.spi.NamedObjectParserFactory} — Factory SPI for creating named object query and procedure parsers.
  • {@link persistence.tools.spi.SchemaValidatorFactory} — Factory SPI for creating database schema validators.
  • {@link persistence.tools.spi.PersistenceLinterFactory} — Generic base factory SPI for discovering linter factory subtypes.

Service Discovery and Usage

Bytecode Enhancement

Obtain an enhancer for a specific JPA specification version (e.g. {@code "3.1"}) via {@link persistence.tools.spi.EnhancerProvider#getEnhancerProvider(String)}: 

{@code
EnhancerProvider provider = EnhancerProvider.getEnhancerProvider("3.1");
Enhancer enhancer = provider.getEnhancer(
    classpathFiles,
    Map.of("enhancement.option.lazy-initialization", true,
           "enhancement.option.dirty-tracking", true));

byte[] enhancedBytes = enhancer.enhance("com.example.Order", originalBytecode);
}

Named Query and Stored Procedure Validation

Obtain a parser factory via {@link persistence.tools.spi.NamedObjectParserFactory#newNamedObjectParserFactory(String)}: 

{@code
NamedObjectParserFactory factory = NamedObjectParserFactory.newNamedObjectParserFactory("3.1");
try (NamedObjectParser parser = factory.newNamedObjectParser(entityClassNames)) {
    NamedObjectDescriptor queryDesc = parser.parseQuery(
        "Order.findByStatus", "SELECT o FROM Order o WHERE o.status = :status");

    NamedObjectDescriptor procDesc = parser.parseStoredProcedure(
        "Order.archive", "sp_archive_orders", Set.of("cutoffDate"));
}
}

Database Schema Validation

Obtain a schema validator factory via {@link persistence.tools.spi.SchemaValidatorFactory#newSchemaValidatorFactory(String)}: 

{@code
SchemaValidatorFactory factory = SchemaValidatorFactory.newSchemaValidatorFactory("3.1");
SchemaValidator validator = factory.newSchemaValidator(entityClassNames);
validator.validateSchema(Map.of(
    "driver",   "org.h2.Driver",
    "url",      "jdbc:h2:mem:testdb",
    "username", "sa",
    "password", ""));
}

Java Platform Module System (JPMS)

The {@code io.github.jpersist.tools.api} module descriptor exports its API packages and declares ServiceLoader dependencies:

  • {@code exports persistence.tools;}
  • {@code exports persistence.tools.spi;}
  • {@code uses persistence.tools.spi.PersistenceServiceProvider;}
  • {@code uses persistence.tools.spi.PersistenceLinterFactory;}
  • {@code uses persistence.tools.spi.NamedObjectParserFactory;}
  • {@code uses persistence.tools.spi.SchemaValidatorFactory;}
  • {@code uses persistence.tools.spi.EnhancerProvider;}

Package Summary

{@link persistence.tools}
