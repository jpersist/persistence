Persistence Tools — Hibernate 5 Provider

The Hibernate Persistence Tools module ({@code io.github.jpersist.tools.hibernate}) implements the persistence tooling SPIs for legacy Java Persistence (JPA 2.0, 2.1, and 2.2, {@code "javax"} namespace) using Hibernate 5.

This module provides build-time bytecode enhancement, AST-based query and stored procedure validation, and JDBC database schema verification for applications running on Java EE / {@code javax.persistence} baselines.

Key Capabilities & Implementations

1. Bytecode Enhancement

{@link hibernate.javax.persistence.tools.HibernateEnhancer} transforms compiled entity classes at build time using Hibernate 5's enhancement engine. It instruments classes for:

  • Lazy-loading proxies and field interception
  • Inline dirty tracking to avoid expensive state snapshots
  • Bidirectional association management and synchronization
  • Extended enhancement optimizations

Enhancement settings can be configured using string property keys or the {@link hibernate.javax.persistence.tools.HibernateEnhancer.Option} enum.

2. Named Query & Stored Procedure Validation

{@link hibernate.javax.persistence.tools.HibernateNamedObjectParser} parses and validates named JPQL queries and stored procedure declarations using Hibernate 5's Abstract Syntax Tree (AST) query translator against the JPA entity metamodel.

3. Database Schema Validation

{@link hibernate.javax.persistence.tools.HibernateSchemaValidator} validates the entity metamodel against a target database schema via JDBC, ensuring tables, columns, data types, and foreign key constraints conform to JPA mappings.

Service Provider Registrations

The module implements and registers the following Service Provider Interfaces (SPI) declared in {@code io.github.jpersist.tools.api}:

  • {@link persistence.tools.spi.NamedObjectParserFactory} — implemented by {@link hibernate.javax.persistence.tools.provider.HibernateNamedObjectParserFactory}
  • {@link persistence.tools.spi.SchemaValidatorFactory} — implemented by {@link hibernate.javax.persistence.tools.provider.HibernateSchemaValidatorFactory}
  • {@link persistence.tools.spi.EnhancerProvider} — implemented by {@link hibernate.javax.persistence.tools.provider.HibernateEnhancerProvider}
  • {@link persistence.tools.spi.PersistenceLinterFactory} — base implementation {@link hibernate.javax.persistence.tools.provider.HibernatePersistenceLinterFactory}
  • {@link persistence.tools.spi.PersistenceServiceProvider} — base implementation {@link hibernate.javax.persistence.tools.provider.HibernatePersistenceServiceProvider}

JPMS Strong Encapsulation

This module enforces strict encapsulation: all implementation packages are hidden and not exported. Consumers interact with this provider exclusively through the API contracts and SPIs provided by {@code io.github.jpersist.tools.api}.

When performing build-time bytecode enhancement on modularized entity projects, entity packages must be opened to this module to permit reflective inspection: 

{@code
module com.example.domain {
    requires java.persistence;
    opens com.example.domain.model to io.github.jpersist.tools.hibernate;
}
}
