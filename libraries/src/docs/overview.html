Lint Persistence Libraries

The Lint Persistence Libraries provide build-time validation of named JPQL queries and stored procedures defined in JPA projects. By compiling query strings against the entity metamodel at build time, syntax errors, unknown entity references, and invalid property paths are caught early — before the application is deployed.

What's New in 2.0.0

Version 2.0.0 introduces the {@link persist.lint.api.spi.NamedObjectParser} and {@link persist.lint.api.spi.NamedObjectParserFactory} APIs, which replace the previous {@link persist.lint.query.spi.QueryParser} and {@link persist.lint.query.spi.QueryParserFactory} (now deprecated). The new API adds support for validating {@link persist.lint.api.NamedObjectType#STORED_PROCEDURE named stored procedures} alongside named queries, and returns rich {@link persist.lint.api.NamedObjectDescriptor} results containing parameter metadata.

Modules

lint-persistence-api
Defines the Service Provider Interface (SPI): {@link persist.lint.api.spi.NamedObjectParser} and {@link persist.lint.api.spi.NamedObjectParserFactory}. This module contains no implementation; provider modules are discovered at runtime through the {@link java.util.ServiceLoader} mechanism.
lint-persistence-jakarta
Jakarta Persistence (JPA 3.x) provider. Uses Hibernate ORM 6 to compile JPQL queries into Semantic Query Model (SQM) trees. See {@link persist.lint.jakarta.JakartaNamedObjectParserFactory}.
lint-persistence-legacy
Legacy {@code javax.persistence} (JPA 2.x) provider. Uses Hibernate 5 and its AST-based query translator to validate JPQL queries. See {@link persist.lint.legacy.LegacyNamedObjectParserFactory}.
lint-persistence-bom
Bill of Materials (BOM) for convenient dependency management of all Lint Persistence modules.

Getting Started

Use {@link persist.lint.api.spi.NamedObjectParserFactory#newNamedObjectParserFactory(String)} to obtain the appropriate factory for a given JPA specification version, then create a {@link persist.lint.api.spi.NamedObjectParser} to validate named queries and stored procedures: 

{@code
    NamedObjectParserFactory factory = NamedObjectParserFactory.newNamedObjectParserFactory("3.1");
    NamedObjectParser parser = factory.newNamedObjectParser(entityClassNames);

    // Validate a named query
    NamedObjectDescriptor queryDescriptor = parser.parseQuery(
        "Order.findByStatus",
        "SELECT o FROM Order o WHERE o.status = :status");

    // Validate a named stored procedure
    NamedObjectDescriptor procDescriptor = parser.parseStoredProcedure(
        "Order.archiveOldOrders",
        "sp_archive_orders",
        Set.of("cutoffDate", "archiveTable"));
}
